# Стратегия подачи контента

## Тон и стиль
- Голос персонажа: АIбанский школьник — простой, ироничный, домашний, без пафоса
- Язык: простой русский, короткие предложения, конкретные действия
- Атмосфера: кухня, стол с бумагами, вечер, кофе, «я тоже в этом застрял»
- Юмор: лёгкий, самоирония, без насмешек. Крючок в первые 2 секунды, затем суть

## Форматы подачи
- **VK Клипы** (основной двигатель охвата): 15–35 сек, крючок в первые 2 сек, один результат, субтитры
- Посты: карточки + короткий текст, готовые промпты, разборы
- Горизонтальные видео 3+ мин (для набора часов просмотра VK Видео)
- Telegram: зеркало + файлы и длинные разборы
- Персонаж в кадре на обложках, аватарах и в ключевых клипах (лицо/голос владельца или персонаж)

## Принципы
- Одна боль = один результат в кадре
- Показывать процесс, а не только итог
- Реальные кейсы и экраны (не только ИИ-картинки)
- Лид-магнит в каждом ключевом материале (чек-лист, промпты, шаблон)
- Только российские модели в публичном контенте (GigaChat, YandexGPT, Алиса)

## Воронка
Клип/пост → бот в личке → бесплатный чек-лист/промпты → созвон/личка → продажа настройки ИИ-ассистента/агента

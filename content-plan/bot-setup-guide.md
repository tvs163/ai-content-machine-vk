# Настройка бота ВК (лид-магнит «10 промптов для самозанятых»)

## Зачем бот
Точка входа в воронку: клип → бот → бесплатный файл → созвон → продажа настройки ИИ-агента.

## Шаги
1. Зайди на vk.com/botfather (или через приложение ВК: Сервисы → Боты → Создать).
2. Команда /newbot. Имя: «ИИ без сложностей», юзернейм: ai_bez_slozhnostey_bot (или свободный аналог).
3. Сохрани токен.
4. Включи long polling или webhook для получения сообщений.
5. Первое сообщение бота (приветствие):
   «Привет! Я — ассистент ИИ без сложностей. Держи 10 готовых промптов для самозанятых: отзывы, заявки, тексты для Авито. Напиши ПРОМПТЫ — и файл придёт в личку.»
6. Триггер: слово «ПРОМПТЫ» (без учёта регистра) → отправка файла prompts/lead-magnet-10-prompts.md.
7. После отправки файла: «Хочешь, чтобы такой агент работал у тебя 24/7? Напиши СОЗВОН».
8. Триггер «СОЗВОН» → сообщение с календарём/формой для записи.

## Лид-магнит: 10 промптов
См. файл prompts/lead-magnet-10-prompts.md — сгенерирован отдельно.

## Техдолг
- Подключить VK API-токен сообщества для автопостинга (когда сообщество будет создано).
- Маркировка рекламы erid — через AdBlogger с автомаркировкой.

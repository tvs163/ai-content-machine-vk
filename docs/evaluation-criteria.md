# Критерии оценки контента и работы машины

## Оценка отдельного клипа / поста
| Критерий | Целевое значение | Комментарий |
|----------|------------------|-----------|
| Досмотр (клип) | ≥ 55% | Если ниже — менять крючок или темп |
| Лайки / сохранения | ≥ 3–5% от охвата | Сохранения важнее лайков |
| Переходы в бота | ≥ 2–4% | Главный индикатор релевантности |
| Комментарии с вопросами | есть | Показывает вовлечённость |
| Соответствие боли | да | Если тема не бьёт в список болей — не публиковать |

## Оценка недели
- Рост подписчиков (органика + реклама)
- Средний досмотр по клипам
- Количество лидов и конверсия в заявку
- Какие рубрики/боли срабатывают лучше — масштабировать
- Что провалилось — убрать или переписать промпты

## Красные флаги (сразу чинить)
- Досмотр < 35% на 3+ клипах подряд
- Нулевые переходы в бота при хорошем охвате
- Комментарии «не понял» / «слишком сложно»
- Падение охвата при росте подписчиков

## Оценка персонажа и визуала
- Узнаваемость лица/стиля АIбанского школьника
- Соответствие бытовой атмосфере (кухня, счета, дом)
- Отсутствие «инопланетного» вида

# AI Content Machine VK

Автономная контент-машина для ВК. Ниша: «ИИ для работы и жизни».
Цель спринта: 1000 подписчиков к 31.10.2026.

## Архитектура
- Оркестрация: Automations (Grok) — ежедневный пайплайн в 09:00 Europe/Samara
- Генерация: GigaChat / YandexGPT (публичный контент), Claude/GPT (черновики)
- Публикация: VK API (клипы, посты, stories) + репост на страницу
- Воронка: бот ВК → лид-магнит (чек-лист промптов) → созвон → продажа настройки ИИ-ассистента
- Монетизация: своя услуга, CPA (Skillbox 16-27%, Практикум 10.8%), AdBlogger, Ozon Blogger, VK Донат, VK Видео (с 1000 подп. + 500 ч)

## Рубрики
1. «Сделал за 5 минут» — клип со скринкастом, GigaChat/YandexGPT решают бытовую задачу
2. Готовые промпты недели — карточка + файл в лид-магните
3. Кейс «до и после» у реального мастера/бизнеса
4. Разбор «какой российский ИИ для чего»
5. Ответы на вопросы подписчиков

## Ограничения (жёсткие)
- Только российские модели в публичном поле: GigaChat, YandexGPT, Алиса. Никаких VPN.
- Только оригинальный контент (правила ПП ВК с 15.04.2025)
- Без ИИ-лиц детей, без медицинских/психологических советов «лечить»
- Лицо/голос Владимира в 2-3 ключевых роликах

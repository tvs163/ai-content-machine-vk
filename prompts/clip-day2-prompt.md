# Клип дня 2 (21.10.2026) — «Скрытые расходы в выписке через YandexGPT»

## Цель клипа
Показать, как YandexGPT анализирует банковскую выписку (CSV/PDF), находит повторяющиеся и скрытые траты и предлагает, что сократить. Бьём в боль «не вижу, куда уходят деньги».

## Промпт для генерации сценария

```
Ты — сценарист коротких вертикальных клипов для ВК (9:16, 20–30 сек) про практическое применение ИИ для самозанятых и микробизнеса в России. Аудитория: 25–55 лет, мастера, самозанятые, владельцы микробизнеса Самары и Тольятти. Тон: спокойный, конкретный, без хайпа.

Задача: напиши сценарий клипа «Три способа найти скрытые расходы в выписке с помощью YandexGPT — без таблиц вручную».

Структура по кадрам:
- 0–2 сек: лицо, текст «Половина расходов — те, о которых ты забыл».
- 2–7 сек: экран, открываем выписку из банка (PDF или CSV), YandexGPT принимает файл.
- 7–14 сек: модель группирует траты по категориям, выделяет три самых крупных и три самых частых мелких платежа.
- 14–20 сек: список «что можно убрать» с суммами, оранжевым акцентом на итоговой экономии.
- 20–25 сек: лицо, текст «Выписка → YandexGPT → список экономии. Ссылка в шапке».
- 25–30 сек: «ИИ без сложностей».

Требования:
1. Реплики не длиннее 12 слов.
2. На экране — по одной фразе-подсказке на кадр.
3. Финальная цифра экономии — оранжевым (#FF6B00).
4. Без слов «революция», «невероятно», «магия».
5. Только российские модели: YandexGPT (GigaChat — как альтернатива).
6. 3 варианта крючка на 0–2 сек.
7. Формат: таблица «Секунды | Кадр | Текст на экране | Реплика | Действие».
```

```
Преобразуй сценарий в SRT. Белый текст, шрифт без засечек 48–60 px, по центру внизу с тенью. Максимум 2 строки, 40 символов. На 14–20 сек — «Экономия: N ₽» оранжевым. Не дублируй крупный текст на экране.
```

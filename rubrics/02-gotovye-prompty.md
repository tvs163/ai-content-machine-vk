# Рубрика: «Готовые промпты недели»

Формат: карточка-изображение + файл (txt/pdf) в лид-магните бота.
5-7 промптов на неделю по одной теме.

Промпт генерации:
"""Сгенерируй 5 готовых промптов для {model} под задачу {task} для {audience}. Каждый промпт: название, текст промпта, ожидаемый результат (1 строка). Промпты должны быть рабочими, без воды. Выведи в формате: № | Название | Промпт | Результат."""

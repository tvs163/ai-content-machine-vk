# Клип дня 1 (20.10.2026) — «ИИ-агент собирает счета из почты»

## Цель клипа
Показать агентный сценарий: модель не пишет текст, а забирает вложения из почты, парсит PDF, считает суммы и выдаёт итог с рекомендацией по экономии. Бьём в боль «собирать данные из разных мест и анализировать».

## Промпт для генерации сценария (вставить в GigaChat / YandexGPT / Claude)

```
Ты — сценарист коротких вертикальных клипов для ВК (9:16, 20–30 сек) про практическое применение ИИ для самозанятых и микробизнеса в России. Аудитория: 25–55 лет, мастера, самозанятые, владельцы микробизнеса Самары и Тольятти. Тон: спокойный, конкретный, без хайпа, без «вау-эффекта».

Задача: напиши сценарий клипа «Как ИИ-агент сам собирает счета из почты и считает расходы за месяц».

Структура по кадрам (строго соблюдай тайминг):
- 0–2 сек: крупный план лица, текст на экране «Счета приходят каждый день. А ты их не считаешь».
- 2–6 сек: запись экрана, открываем почту, папка «Счета», ИИ-агент забирает вложения.
- 6–12 сек: агент парсит PDF, вытаскивает сумму, дату, поставщика, складывает в таблицу.
- 12–18 сек: итоговая цифра за месяц крупно, рядом — сколько можно сэкономить, убрав три самые частые траты.
- 18–23 сек: лицо снова, текст «Хочешь такой агент? Ссылка в шапке».
- 23–30 сек: логотип/надпись «ИИ без сложностей».

Требования:
1. Каждая реплика — не длиннее 12 слов, чтобы успеть произнести за отведённое время.
2. На кадрах с экраном — по одной фразе-подсказке, что зритель видит.
3. Финальная цифра экономии — оранжевым, остальные — белым.
4. Не используй слова «революция», «невероятно», «магия» — звучит как реклама.
5. Упомяни только российские модели: GigaChat или YandexGPT.
6. Добавь 3 варианта крючка на 0–2 секунду (выбери один или предложи свой).
7. Формат ответа: таблица с колонками «Секунды», «Кадр», «Текст на экране», «Реплика», «Действие».
```

## Промпт для генерации субтитров

```
Возьми сценарий клипа (таблица с колонками «Секунды», «Кадр», «Текст на экране», «Реплика») и преобразуй его в файл субтитров SRT.

Правила:
1. Каждая реплика — отдельный субтитр с таймкодом.
2. Белый текст, шрифт без засечек (например, Inter или Roboto), размер 48–60 px.
3. Позиция: по центру внизу кадра, с лёгкой тенью для читаемости на любом фоне.
4. Максимум 2 строки на субтитр, не более 40 символов в строке.
5. На кадрах 12–18 сек (итоговая цифра) — текст «Экономия: N ₽» оранжевым цветом (#FF6B00), остальные субтитры белые.
6. Не дублируй текст, который уже крупно на экране — субтитр только для речи.
7. Выведи результат как .srt файл и отдельно список субтитров текстом для проверки.
```
